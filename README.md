# Le Garage des Petites Voitures

Jeux éducatifs sur le thème des voitures, de la petite section au CP : 31 jeux qui parlent à l'enfant, un niveau qui s'adapte tout seul, des aides pour les enfants en situation de handicap, et un bilan pour les parents.
